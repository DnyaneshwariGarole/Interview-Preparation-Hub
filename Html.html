History of HTML

HTML was invented by Tim Berners-Lee in 1989.

HTML1 → Basic structure in 1991
HTML2 → Standard version in 1993
HTML3 → Added tables in 1995
HTML4 → Added CSS support in 1997
HTML5 → Latest version with audio, video, semantic tags in 2014

Difference Between HTML4 & HTML5?

i. In HTML 4 media tags not present
ii. Semantic tags was not introduced
iii. So many input attributes or from attributes were not present
iv. Default Storage of browser is not available

i. In HTML 5 media tags are present
ii. Semantic tags are introduced
iii. All inputs & from attribute are available

Types of Element?

There are 3 types of Elements

    1. Inline Element
  • Starts in same line
  • Occupies only content width
  • Allows other inline element to sit beside it
  • Doesn't accept top and bottom margin
    2. Block Element
  • Starts in new line
  • Occupies entire width of webpages
  • Won't allow any other elementto sit beside it
  • Accepts top and bottom margin
    3. Void Element
  • All unpair tags are void elements

Block vs Inline elements?

HTML elements are categorized into block-level and inline elements based on their behavior.

Block Elements:
- They always start on a new line.
- They take full width available in the container.
- Examples: div, p, h1, section

Inline Elements:
- They do not start on a new line.
- They take only the width required by content.
- Examples: span, a, img

This difference is important for layout design and styling using CSS.

Difference between id and class?

Both id and class are attributes used to target HTML elements for styling or scripting.

id:
- Must be unique in a page.
- Used to identify a single element.
- Higher priority in CSS.

class:
- Can be used multiple times.
- Used to group multiple elements.
- More reusable and flexible.

In practice, class is preferred for styling and id is used for unique elements.

What are empty elements?

Empty elements are HTML elements that do not have closing tags and do not contain content.

They are also called self-closing or void elements.

Examples:
- br (line break)
- hr (horizontal line)
- img (image)
- input (form field)

These elements are used when no inner content is required.

What is hyperlink?

A hyperlink is used to navigate from one page to another or to a different section of the same page.

It is created using the anchor (a) tag with the href attribute.

Example:
<a href="https://example.com">Click Here</a>

Hyperlinks are essential for website navigation and connecting web pages.

What is table in HTML?

A table is used to display data in a structured format using rows and columns.

Main Tags:
- table → defines table
- tr → table row
- th → table header
- td → table data

Tables are commonly used for displaying reports, data sets, and structured information.

What is list?

Lists are used to group related items in a structured format.

Types of Lists:
1. Ordered List (ol) → shows items in sequence (numbers/letters)
2. Unordered List (ul) → shows items with bullets
3. Description List (dl) → used for definitions

What is audio/video tag?

HTML5 introduced audio and video tags to embed media content directly into webpages.

audio tag: used to play sound files
video tag: used to play video files

These tags support controls like play, pause, and volume, improving user experience without requiring external plugins.

What is local storage?

Local storage is a web storage feature that allows data to be stored in the browser.

Key Features:
- Data persists even after page reload or browser restart
- Stores data in key-value format

It is commonly used to store user preferences and temporary application data.

What is accessibility?

Accessibility means designing websites so that all users, including people with disabilities, can use them effectively.

Examples:
- Using alt text for images
- Proper heading structure
- Keyboard navigation support

It improves usability and is an important part of modern web development.
