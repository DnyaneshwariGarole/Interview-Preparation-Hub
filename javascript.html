JavaScript Interview Questions

What is JavaScript?

JavaScript is a high-level, interpreted programming language used to make web pages interactive. It allows developers to handle events, manipulate the DOM, perform calculations, and update content dynamically without reloading the page. It is widely used in both frontend and backend development.

Difference between var, let, and const?

var is function-scoped and can be redeclared and updated. let is block-scoped and cannot be redeclared in the same scope but can be updated. const is also block-scoped but its value cannot be reassigned after initialization. Using let and const is recommended in modern JavaScript.

What is closure?

A closure is a function that remembers variables from its outer scope even after the outer function has executed. It allows data to be preserved and is commonly used in callbacks, data privacy, and function factories.

What is DOM?

DOM (Document Object Model) represents the HTML document as a tree structure. JavaScript can access, modify, and manipulate elements in the DOM dynamically, allowing interactive web applications.

What are events?

Events are actions triggered by the user or browser, such as clicks, keypresses, or page loads. JavaScript listens to these events and executes functions to respond, enabling interactivity.

What is a function?

A function is a reusable block of code designed to perform a specific task. Functions help organize code, improve readability, and avoid repetition.

What is hoisting?

Hoisting is JavaScript's default behavior of moving variable and function declarations to the top of their scope during compilation. However, only declarations are hoisted, not initializations.

What is event bubbling?

Event bubbling is a mechanism where an event starts from the target element and propagates upward through its parent elements in the DOM hierarchy.

What is event delegation?

Event delegation is a technique where a single event listener is added to a parent element to handle events for multiple child elements. It improves performance and reduces memory usage.

What is strict mode?

Strict mode is a feature in JavaScript that enables stricter parsing and error handling. It helps catch common coding mistakes and prevents the use of unsafe actions.

What is data type in JavaScript?

JavaScript has dynamic data types including primitive types (string, number, boolean, null, undefined, symbol, bigint) and non-primitive types like objects and arrays.

What is type coercion?

Type coercion is the automatic conversion of one data type to another by JavaScript. It can be implicit (automatic) or explicit (manual), and can sometimes lead to unexpected results.

What is undefined vs null?

undefined means a variable has been declared but not assigned a value. null is an assignment value that represents no value or empty value.

What is NaN?

NaN stands for "Not a Number". It is returned when a mathematical operation fails or when a non-numeric value is used in a numeric operation.

What is a Promise?

A Promise is an object used to handle asynchronous operations. It represents a value that may be available now, later, or never. It has three states: pending, fulfilled, and rejected.

What is async/await?

async/await is a modern way to handle asynchronous operations. The async keyword makes a function return a promise, and await pauses execution until the promise is resolved, making code easier to read.

What is arrow function?

Arrow functions provide a shorter syntax for writing functions. They do not have their own 'this' keyword and inherit it from the surrounding scope.

Difference between == and ===?

== compares values after type conversion, while === compares both value and type strictly. Using === is recommended to avoid unexpected results.

What is localStorage?

localStorage is used to store data in the browser with no expiration time. The data remains even after the browser is closed and is useful for saving user preferences.

What is sessionStorage?

sessionStorage stores data only for the duration of the page session. The data is cleared when the browser tab is closed.

What is callback function?

A callback function is a function passed as an argument to another function and is executed later, often used in asynchronous operations.

What is scope in JavaScript?

Scope determines where variables are accessible. It includes global scope, function scope, and block scope.

What is closure vs scope?

Scope defines where variables can be accessed, while closure allows a function to remember variables from its outer scope even after execution.

What is setTimeout?

setTimeout is a function used to execute code after a specified delay. It is commonly used for asynchronous operations.

What is setInterval?

setInterval executes a function repeatedly at a fixed time interval until it is stopped using clearInterval.

What is JSON?

JSON (JavaScript Object Notation) is a lightweight data format used to store and exchange data between server and client.

What is fetch API?

Fetch API is used to make HTTP requests to servers. It returns promises and is commonly used to get or send data asynchronously.

What is difference between synchronous and asynchronous?

Synchronous code runs line by line, blocking execution. Asynchronous code runs independently, allowing other operations to continue, improving performance and responsiveness.
