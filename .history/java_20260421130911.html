Java Interview Questions

What is Java?

Java is a high-level, object-oriented, platform-independent programming language. It follows the principle of "Write Once, Run Anywhere" using JVM.

What is OOP?

Object-Oriented Programming includes concepts like encapsulation, inheritance, polymorphism, and abstraction to design modular programs.

What is a class?

A class is a blueprint for creating objects. It defines properties (variables) and behaviors (methods).

What is an object?

An object is an instance of a class that contains data and methods.

What is inheritance?

Inheritance allows one class to acquire properties of another class, promoting code reuse.

What is polymorphism?

Polymorphism allows methods to perform different tasks based on input. Types: compile-time and runtime.

What is encapsulation?

Encapsulation is wrapping data and methods together and restricting access using access modifiers.

What is abstraction?

Abstraction hides implementation details and shows only essential features using abstract classes and interfaces.

What is interface?

An interface contains abstract methods that must be implemented by classes. It supports multiple inheritance.

What is exception handling?

Exception handling is used to handle runtime errors using try, catch, finally, throw, and throws.

What is JVM?

Java Virtual Machine runs Java bytecode and makes Java platform-independent.

What is JDK and JRE?

JDK is development kit, JRE provides runtime environment, JVM executes code.

What is method overloading?

Multiple methods with same name but different parameters.

What is method overriding?

Subclass provides specific implementation of parent method.

What is String?

String is an immutable class used to store text data.

What is collection framework?

Provides classes like List, Set, Map to manage groups of objects.
