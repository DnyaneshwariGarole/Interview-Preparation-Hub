HTML

Important questions you should know before interviews.

What is HTML?

HTML (HyperText Markup Language) is used to structure content on the web.

What are semantic tags?

Tags like <header>, <footer>, <article> that give meaning to content.

Difference between div and span?

Div is block-level, span is inline element.

What is the difference between HTML and HTML5?

HTML5 supports new tags like video, audio, semantic tags and APIs.

What is a form in HTML?

Used to collect user input like name, email, password.

What are different input types?

text, password, email, number, date, file, checkbox, radio.

What is the purpose of alt attribute?

Provides description for images (important for accessibility).

What is iframe?

Used to embed another webpage inside current page.

What is meta tag?

Defines metadata like charset, description, viewport.

What is the difference between id and class?

id is unique, class can be used multiple times.

What is block vs inline elements?

Block takes full width, inline takes only required width.

What is DOCTYPE?

Defines HTML version and helps browser render correctly.

What is SEO in HTML?

Using proper tags and structure to improve search engine ranking.

What are empty elements?

Elements without closing tags like <br>, <img>.

Quick Notes

  • HTML is not a programming language.
  • Use semantic tags for better readability.
  • Always use alt attribute in images.

Interview Tips

  • Explain with examples.
  • Don’t just define — show use case.
  • Be clear about basics.
