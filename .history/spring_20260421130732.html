Spring & Backend Interview Questions

What is Spring Boot?

Spring Boot is a framework that simplifies building Java applications by reducing configuration and providing built-in features.

What is Dependency Injection?

It is a design pattern where objects are provided automatically instead of creating them manually.

What is Spring MVC?

It is a framework based on Model-View-Controller pattern for building web applications.

What is REST API?

REST API allows communication between client and server using HTTP methods like GET, POST, PUT, DELETE.

What is Hibernate?

Hibernate is an ORM framework that maps Java objects to database tables.

What is JPA?

Java Persistence API is a specification used for ORM in Java.

What is JDBC?

Java Database Connectivity is used to connect Java applications with databases.

What is @RestController?

It is used to create REST APIs and returns JSON response.

What is @Autowired?

It is used for automatic dependency injection.

What is application.properties?

Used to configure Spring Boot application settings.

What is bean?

Bean is an object managed by Spring container.

What is IOC?

Inversion of Control means control of object creation is given to Spring container.

What is @Entity?

Marks a class as a database table in Hibernate.

What is @Repository?

Used for database access layer.

What is @Service?

Used for business logic layer.

What is layered architecture?

Separates application into controller, service, and repository layers.
