HTML Interview Questions

Revise important HTML concepts with clear explanations.

What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create web pages. It defines the structure of a webpage using elements like headings, paragraphs, links, images, and forms. HTML does not provide logic or styling; it only structures the content which is later styled using CSS and made interactive using JavaScript.

What are semantic HTML elements?

Semantic elements clearly describe their meaning in a human and machine-readable way. Examples include <header>, <footer>, <article>, <section>, and <nav>. They improve code readability, accessibility, and SEO because search engines and screen readers can better understand the content structure.

Difference between div and span?

The <div> tag is a block-level element that takes full width and starts on a new line, commonly used for layout. The <span> tag is an inline element that only takes the necessary width and is used to style or group small parts of text without breaking the flow.

What is the difference between HTML and HTML5?

HTML5 is the latest version of HTML and introduces new semantic elements like <article> and <section>, multimedia support using <audio> and <video>, and APIs like local storage and geolocation. It removes the need for external plugins like Flash and improves performance and mobile support.

What is a form and why is it used?

A form is used to collect user input such as names, emails, passwords, and other data. It contains elements like input fields, labels, buttons, and text areas. The collected data is usually sent to a server for processing using methods like GET or POST.

What are different input types in HTML?

HTML provides multiple input types such as text, password, email, number, date, file, checkbox, and radio buttons. Each type is designed for a specific kind of user input and helps in validation and improving user experience.

What is the purpose of the alt attribute?

The alt attribute provides alternative text for an image if it fails to load. It is also important for accessibility as screen readers use it to describe images to visually impaired users. Additionally, it helps improve SEO.

What is iframe?

The iframe tag is used to embed another HTML page within the current page. It is commonly used for embedding videos, maps, or external content. However, it should be used carefully due to performance and security concerns.

What is the meta tag?

Meta tags provide metadata about the HTML document such as character encoding, viewport settings, and page description. They are placed inside the head section and are important for SEO and proper rendering.

Difference between id and class?

The id attribute is unique and used to identify a single element, while class can be used on multiple elements. In CSS, id has higher specificity than class.

What are block and inline elements?

Block elements take full width and start on a new line (e.g., div, p, h1). Inline elements only take the required width and stay in the same line (e.g., span, a, img).

What is DOCTYPE?

DOCTYPE is a declaration at the top of an HTML document that tells the browser which version of HTML is being used. It ensures the page is rendered correctly.
