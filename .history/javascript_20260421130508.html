JavaScript Interview Questions

What is JavaScript?

JavaScript is a programming language used to make web pages interactive. It allows you to handle events, manipulate the DOM, and perform operations dynamically without reloading the page.

Difference between var, let, and const?

var has function scope and can be redeclared. let has block scope and cannot be redeclared in the same scope. const is also block scoped but its value cannot be reassigned after declaration.

What is closure?

A closure is a function that remembers variables from its outer scope even after the outer function has finished execution. It is useful for data privacy and callbacks.

What is DOM?

DOM (Document Object Model) represents the structure of HTML as a tree. JavaScript can use DOM to access and modify elements dynamically.

What are events?

Events are actions like click, hover, keypress triggered by user or browser. JavaScript listens and responds to these events.

What is a function?

A function is a block of reusable code that performs a specific task. It helps in modular and clean coding.

What is hoisting?

Hoisting is JavaScript's behavior of moving variable and function declarations to the top of their scope before execution.

What is event bubbling?

Event bubbling is when an event starts from the target element and propagates upward to parent elements.

What is a Promise?

A Promise is used to handle asynchronous operations. It has three states: pending, fulfilled, and rejected.

What is async/await?

async/await is a modern way to handle asynchronous code in JavaScript. It makes code easier to read compared to promises.

What is arrow function?

Arrow functions provide a shorter syntax and do not have their own 'this' keyword.

Difference between == and ===?

== compares values with type conversion, while === compares both value and type strictly.

What is localStorage?

localStorage allows storing data in the browser without expiration. It is useful for saving user preferences.

What is sessionStorage?

sessionStorage stores data only for the session and clears when the tab is closed.

What is callback function?

A callback is a function passed as an argument to another function and executed later.

What is scope in JavaScript?

Scope defines where variables are accessible. Types include global, function, and block scope.
