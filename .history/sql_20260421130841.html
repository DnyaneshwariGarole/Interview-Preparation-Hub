SQL

What is SQL?

SQL is a language used to manage and manipulate relational databases.

What is primary key?

A primary key uniquely identifies each row in a table and cannot be null.

What is foreign key?

It is used to link two tables and maintain referential integrity.

What are joins?

Joins combine rows from multiple tables. Types include INNER, LEFT, RIGHT, FULL.

What is normalization?

Normalization removes redundancy and improves data consistency.

What is index?

Index improves query performance by allowing faster data retrieval.

What is GROUP BY?

Used to group rows that have same values.

What is HAVING?

Used to filter grouped data after GROUP BY.

Difference between WHERE and HAVING?

WHERE filters rows before grouping, HAVING filters after grouping.

What is aggregate function?

Functions like COUNT, SUM, AVG used for calculations.

What is subquery?

A query inside another query.

What is view?

A virtual table based on SQL query.

What is DELETE vs TRUNCATE?

DELETE removes specific rows, TRUNCATE removes all rows quickly.

What is constraint?

Rules applied on columns like NOT NULL, UNIQUE, PRIMARY KEY.

What is ACID?

Atomicity, Consistency, Isolation, Durability ensure reliable transactions.

What is database?

Collection of structured data stored electronically.
