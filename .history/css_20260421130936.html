CSS Interview Questions

What is CSS?

CSS (Cascading Style Sheets) is used to style and layout web pages. It controls colors, fonts, spacing, positioning, and responsiveness of elements. It works along with HTML to make websites visually attractive.

Explain the CSS Box Model.

The box model consists of content, padding, border, and margin. It defines the layout and spacing of elements. Understanding it is important for designing layouts properly.

What is Flexbox?

Flexbox is a layout module used to align items in a row or column. It makes it easy to center elements and distribute space dynamically.

What is CSS Grid?

CSS Grid is a 2D layout system that allows you to create complex layouts using rows and columns. It is more powerful than flexbox for grid-based layouts.

Difference between margin and padding?

Margin controls outer spacing between elements, while padding controls space inside the element between content and border.

What is display property?

It defines how elements are displayed on the page such as block, inline, inline-block, flex, and grid.

What is position property?

It controls element positioning. Types include static, relative, absolute, fixed, and sticky.

What is z-index?

z-index controls stacking order of elements. Higher value appears on top.

What is specificity?

Specificity determines which CSS rule is applied when multiple rules target the same element. Inline styles have highest priority.

Inline vs Internal vs External CSS?

Inline CSS is applied directly in element, internal is inside style tag, and external CSS is in separate file. External is best practice.

What is responsive design?

Responsive design ensures website looks good on all devices using media queries, flexible layouts, and fluid images.

What are media queries?

Media queries are used to apply CSS based on screen size, device type, or resolution.

What is overflow?

It controls what happens when content overflows container. Values: hidden, scroll, auto.

What is opacity?

It controls transparency of an element from 0 (invisible) to 1 (visible).

Difference between class and id selector?

ID selector is unique and has higher priority, class can be reused.

What is pseudo-class?

Pseudo-classes define special states like :hover, :focus, :active.
