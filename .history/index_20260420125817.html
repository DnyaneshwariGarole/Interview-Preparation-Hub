HTML Questions

What is HTML?

HTML is used to structure web pages.

Semantic tags?

Tags like header, footer which give meaning.

Div vs Span?

Div is block, span is inline.

What is form?

Used to collect user input.

Meta tag?

Provides page information.

Quick Notes

HTML is only for structure, not logic.

Interview Tips

Explain tags with examples.

CSS Questions

What is CSS?

Used for styling web pages.

Box Model?

Margin, border, padding, content.

Flexbox?

Layout system for alignment.

Position types?

Static, relative, absolute, fixed.

Quick Notes

CSS controls layout and design.

Interview Tips

Practice small layouts.

Java Questions

What is Java?

Object oriented language.

OOP concepts?

Encapsulation, inheritance, polymorphism.

Class?

Blueprint of object.

Interface?

Contains abstract methods.

Quick Notes

Java is platform independent.

Interview Tips

Focus on OOP concepts.

Normalization?

SQL?

Query language.

Quick Notes

DBMS stores structured data.
