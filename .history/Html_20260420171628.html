HTML Interview Questions

What is HTML?

HTML is a markup language used to structure web content. It defines elements like headings, paragraphs, images, and links.

What are semantic elements?

Semantic elements describe meaning clearly like header, footer, article. They improve readability and SEO.

Difference between div and span?

Div is block-level and span is inline element used for small content styling.

What is HTML5?

HTML5 is the latest version with new tags, APIs, multimedia support and better performance.

What is form?

Form is used to collect user data like name, email, password etc.

GET vs POST?

GET sends data in URL, POST sends data in body and is more secure.

What is iframe?

Used to embed another webpage inside current page.

What is alt attribute?

Provides description of image for accessibility and SEO.

What is meta tag?

Provides metadata like charset, viewport and SEO info.

Block vs Inline elements?

Block takes full width, inline takes only required space.

What is DOCTYPE?

It defines the HTML version and ensures proper rendering.

Difference between id and class?

id is unique, class can be reused multiple times.

What are empty elements?

Elements without closing tags like br, hr, img.

What is hyperlink?

Link created using anchor tag to navigate between pages.

What is table in HTML?

Used to display data in rows and columns using table, tr, td.

What is list?

Used to group items. Types: ordered, unordered, description list.

What is audio/video tag?

Used to embed multimedia directly without plugins.

What is local storage?

Used to store data in browser without expiration.

What is accessibility?

Making web usable for all users including disabled people.

What is SEO?

Improving website visibility on search engines.
