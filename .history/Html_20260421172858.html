Questions on HTML

What is HTML?

HTML stands for Hypertext Markup Language & It is a root frontend language, reference or link to visualize the content on UI(User Interface) with the Help of pre-defined tags which all browser understandable

History of HTML

HTML was invented by Tim Berners-Lee in 1989.

HTML1 → Basic structure in 1991
HTML2 → Standard version in 1993
HTML3 → Added tables in 1995
HTML4 → Added CSS support in 1997
HTML5 → Latest version with audio, video, semantic tags in 2014

Difference Between HTML4 & HTML5?

i. In HTML 4 media tags not present
ii. Semantic tags was not introduced
iii. So many input attributes or from attributes were not present
iv. Default Storage of browser is not available

i. In HTML 5 media tags are present
ii. Semantic tags are introduced
iii. All inputs & from attribute are available
iv. local Storage is a Default browser

What is DOCTYPE?

DOCTYPE is used to tell browser which version of HTML is used.

It ensures proper rendering of webpage.

Example:
<!DOCTYPE html>

What are HTML Tags?

It is root tag of html which comes with lang attribute. HTML tags are predefined keywords used to create elements.

Types:
1. Paired Tag → This will consist two tags as a pair first tag is opening tag & second tag is closing tag
2. Unpaired Tag → This will have only single tag hence it is called self closing

What is Element?

Element = Opening tag + Content + Closing tag

Example:
<p>Hello</p>

Types of Element?

There are 3 types of Elements

    Inline Element
  • Starts in same line
  • Occupies only content width
  • Allows other inline element to sit beside it
  • Doesn't accept top and bottom margin
Block Element
starts in new line
3. Void Element --> All unpair tags are void elements

What is Attribute?

Attribute gives extra information to tag.

Syntax:
tag attribute="value"

Example:
<a href="google.com">Click</a>

What are semantic elements?

Semantic tags clearly define meaning of content.

Examples:
header, footer, article, section, nav

Advantages:
✔ Better SEO
✔ Better readability
✔ Helps browser understand structure

Difference between div and span?

div → block level element (full width)
span → inline element (required width only)

What is HTML5?

HTML5 is latest version of HTML.

Features:
✔ Audio & Video support
✔ Semantic tags
✔ Local storage
✔ No need of plugins

What is form?

Form is used to collect user input and send to backend.

Used in:
Login
Registration
Contact forms
Payment forms

GET vs POST?

GET:
Data visible in URL
Less secure

POST:
Data hidden
More secure

What is iframe?

iframe is used to insert another webpage inside current webpage.

Example:
YouTube video, Google Maps

What is alt attribute?

alt attribute gives description of image.

Used when:
Image not loaded
For accessibility

What is meta tag?

Meta tag provides metadata about webpage.

Used for:
SEO
Responsive design
Charset

Block vs Inline elements?

Block:
Takes full width
New line

Inline:
Takes required width
Same line

Difference between id and class?

id:
Unique
Used once

class:
Reusable
Used multiple times

What are empty elements?

Elements without closing tag.

Examples:
br, hr, img, input

What is hyperlink?

Hyperlink is created using anchor tag.

Used to navigate between pages.

What is table in HTML?

Table is used to display data in rows and columns.

Tags:
table, tr, th, td

What is list?

Lists are used to group items.

Types:
1. Ordered list
2. Unordered list
3. Description list

What is audio/video tag?

Used to insert media in webpage.

audio → sound
video → video file

What is local storage?

Local storage is used to store data in browser permanently.

Data will not delete after refresh.

What is accessibility?

Accessibility means making website usable for all users including disabled users.

Example:
screen readers, alt text

What is SEO?

SEO (Search Engine Optimization) is used to improve website ranking on search engines.

Helps website appear on Google.
