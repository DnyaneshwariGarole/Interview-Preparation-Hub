Java Interview Questions

What is Java?

Java is a high-level, object-oriented, platform-independent programming language. It follows the principle of "Write Once, Run Anywhere" using JVM, which allows Java programs to run on any system without recompilation.

What is OOP?

Object-Oriented Programming is a programming paradigm based on objects. It includes concepts like encapsulation, inheritance, polymorphism, and abstraction to build modular, reusable, and scalable applications.

What is a class?

A class is a blueprint or template used to create objects. It defines variables (data members) and methods (functions) that describe the behavior of the object.

What is an object?

An object is an instance of a class. It represents a real-world entity and contains both state (variables) and behavior (methods).

What is inheritance?

Inheritance is a mechanism where one class acquires the properties and behaviors of another class. It promotes code reuse and supports hierarchical classification.

What is polymorphism?

Polymorphism allows one method to have multiple forms. It can be achieved through method overloading (compile-time) and method overriding (runtime), improving flexibility.

What is encapsulation?

Encapsulation is the process of wrapping data and methods into a single unit. It restricts direct access using access modifiers, ensuring data security.

What is abstraction?

Abstraction hides internal implementation details and shows only essential features. It is achieved using abstract classes and interfaces, improving code simplicity.

What are access modifiers?

Access modifiers define the visibility of classes, methods, and variables. Types include public, private, protected, and default. They help in controlling access and ensuring security.

What is constructor?

A constructor is a special method used to initialize objects. It has the same name as the class and is automatically called when an object is created.

What is this keyword?

The 'this' keyword refers to the current object. It is used to access instance variables, call constructors, and resolve naming conflicts.

What is static keyword?

The static keyword is used for memory management. Static variables and methods belong to the class rather than objects and are shared among all instances.

What is interface?

An interface is a collection of abstract methods. It is used to achieve abstraction and supports multiple inheritance. Classes implement interfaces using the 'implements' keyword.

What is exception handling?

Exception handling is used to handle runtime errors gracefully. It uses try, catch, finally, throw, and throws keywords to prevent program crashes.

What is JVM?

JVM (Java Virtual Machine) executes Java bytecode. It provides platform independence by converting bytecode into machine-specific instructions.

What is JDK and JRE?

JDK (Java Development Kit) is used for development and includes JRE. JRE (Java Runtime Environment) provides libraries and JVM to run Java programs.

What is method overloading?

Method overloading allows multiple methods with the same name but different parameters in the same class. It improves code readability and flexibility.

What is method overriding?

Method overriding allows a subclass to provide a specific implementation of a method already defined in the parent class. It supports runtime polymorphism.

What is String?

String is a class used to represent text data. It is immutable, meaning once created, its value cannot be changed. Any modification creates a new object.

What is collection framework?

The collection framework provides classes and interfaces like List, Set, and Map to store and manipulate groups of objects efficiently.

Difference between Array and ArrayList?

Arrays have fixed size and can store primitive or object types. ArrayList is dynamic, can grow or shrink, and only stores objects. ArrayList provides more flexibility.

What is final keyword?

The final keyword is used to restrict modification. A final variable cannot be changed, a final method cannot be overridden, and a final class cannot be inherited.

What is multithreading?

Multithreading allows concurrent execution of two or more threads. It improves performance and CPU utilization in applications.

What is synchronization?

Synchronization is used to control access to shared resources in multithreading. It prevents data inconsistency and thread conflicts.

What is equals() and hashCode()?

equals() compares object values, while hashCode() returns a hash value used in hashing collections like HashMap. Both should be overridden together.

What is garbage collection?

Garbage collection automatically removes unused objects from memory. It helps in memory management and prevents memory leaks.

What is wrapper class?

Wrapper classes convert primitive data types into objects. Examples include Integer, Double, and Character. They are used in collections and APIs.

What is difference between == and equals()?

'==' compares references (memory location), while equals() compares actual content or values of objects.
