Spring & Backend Interview Questions

What is Spring Boot?

Spring Boot is an extension of the Spring framework that simplifies the development of Java applications. It reduces the need for complex XML configuration and provides features like auto-configuration, embedded servers (such as Tomcat), and production-ready tools. It helps developers quickly build standalone, scalable applications.

What is Dependency Injection?

Dependency Injection is a design pattern where objects are provided to a class instead of being created inside it. Spring manages these dependencies automatically, making code loosely coupled, easier to test, and maintainable.

What is Spring MVC?

Spring MVC is a web framework based on the Model-View-Controller pattern. It separates application logic into three parts: Model (data), View (UI), and Controller (handles requests). This separation improves maintainability and scalability.

What is REST API?

REST (Representational State Transfer) API is a way for client and server to communicate using HTTP methods like GET, POST, PUT, and DELETE. It is stateless, meaning each request contains all necessary information. It commonly returns data in JSON format.

What is Hibernate?

Hibernate is an ORM (Object Relational Mapping) framework that maps Java objects to database tables. It reduces the need for writing SQL queries manually and provides features like caching, lazy loading, and automatic table mapping.

What is JPA?

JPA (Java Persistence API) is a specification that defines how Java objects are mapped to database tables. Hibernate is one of the implementations of JPA. It standardizes ORM practices in Java.

What is JDBC?

JDBC (Java Database Connectivity) is an API used to connect Java applications to databases. It allows executing SQL queries, retrieving results, and managing database connections.

What is @RestController?

@RestController is a Spring annotation used to create RESTful web services. It combines @Controller and @ResponseBody, meaning it directly returns data (usually JSON) instead of rendering a view.

What is @RequestMapping?

@RequestMapping is used to map HTTP requests to handler methods in a controller. It can specify URL paths, request methods, and parameters to handle incoming requests.

What is @GetMapping, @PostMapping?

These are shortcut annotations for handling specific HTTP methods. @GetMapping is used for retrieving data, while @PostMapping is used for creating new resources.

What is @PathVariable?

@PathVariable is used to extract values from the URL path and pass them to controller methods. It is commonly used in REST APIs for dynamic data.

What is @RequestBody?

@RequestBody is used to bind HTTP request data (usually JSON) to a Java object. It allows sending complex data structures from client to server.

What is Bean Scope?

Bean scope defines the lifecycle and visibility of a Spring bean. Common scopes include singleton (one instance), prototype (new instance each time), request, and session.

What is Spring Container?

Spring container is the core of Spring framework that manages beans, dependency injection, and lifecycle of objects. It reads configuration and creates objects accordingly.

What is Auto Configuration?

Auto-configuration is a feature of Spring Boot that automatically configures application components based on dependencies present in the classpath. It reduces manual setup.

What is @Autowired?

@Autowired is used for automatic dependency injection in Spring. It automatically injects required beans into a class, reducing manual configuration.

What is application.properties?

application.properties is a configuration file used in Spring Boot to define application settings like database connection, server port, logging, and more.

What is bean?

A bean is an object that is created, managed, and controlled by the Spring container. Beans are defined using annotations or configuration files.

What is IOC?

Inversion of Control (IOC) means the control of object creation and management is transferred from the developer to the Spring container, making the code loosely coupled.

What is @Entity?

@Entity is used in JPA to mark a class as a database table. Each instance of the class represents a row in the table.

What is @Repository?

@Repository is used in the data access layer. It handles database operations and interacts with the database.

What is @Service?

@Service is used in the service layer to define business logic. It acts as a bridge between controller and repository.

What is layered architecture?

Layered architecture divides application into layers like Controller (presentation), Service (business logic), and Repository (data access), improving maintainability.

What is DTO?

DTO (Data Transfer Object) is used to transfer data between layers. It helps in reducing unnecessary data exposure and improves performance.

What is validation in Spring?

Validation ensures that incoming data is correct and meets required conditions. Spring provides annotations like @NotNull, @Size, and @Email for validation.

What is exception handling in Spring?

Spring provides global exception handling using @ControllerAdvice and @ExceptionHandler. It helps in handling errors centrally and returning proper responses.

What is Spring Security?

Spring Security is a framework used to secure applications. It provides authentication, authorization, and protection against attacks like CSRF.

What is JWT?

JWT (JSON Web Token) is used for secure authentication. It stores user information in a token and is commonly used in REST APIs.

What is microservices?

Microservices architecture divides an application into small independent services. Each service runs separately and communicates via APIs, improving scalability.

What is API testing?

API testing verifies that APIs work correctly. Tools like Postman are used to test endpoints, validate responses, and ensure performance.
