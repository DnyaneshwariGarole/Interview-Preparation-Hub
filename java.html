Java Interview Questions

What is Java?

Java is a high-level, object-oriented programming language developed by Sun Microsystems. It is platform-independent, meaning code written once can run on any system using the Java Virtual Machine (JVM). Java follows the principle of "Write Once, Run Anywhere" and is widely used for web, desktop, and enterprise applications.

What is OOP?

Object-Oriented Programming (OOP) is a programming approach that uses objects to design applications. It helps in organizing code into reusable components. The main principles include encapsulation, inheritance, polymorphism, and abstraction, which make the code more secure, scalable, and maintainable.

What is a class?

A class is a blueprint or template used to create objects. It defines properties (variables) and behaviors (methods) that the objects created from it will have. For example, a class "Car" can have attributes like color and speed, and methods like start() and stop().

What is an object?

An object is an instance of a class. It represents a real-world entity and contains both data (state) and methods (behavior). For example, if "Car" is a class, then a specific car like "Red BMW" is an object of that class.

What is inheritance?

Inheritance is a feature that allows one class to acquire properties and methods of another class. It helps in code reusability and reduces duplication. The class that inherits is called the child class, and the class being inherited from is called the parent class.

What is polymorphism?

Polymorphism means "many forms". It allows methods to perform different tasks based on input. It is of two types: compile-time polymorphism (method overloading) and runtime polymorphism (method overriding). It improves flexibility and readability of code.

What is encapsulation?

Encapsulation is the process of wrapping data and methods into a single unit (class). It restricts direct access to data using access modifiers like private, and provides controlled access through getter and setter methods, improving security.

What is abstraction?

Abstraction means hiding internal implementation details and showing only important features. It reduces complexity and improves code clarity. It is achieved using abstract classes and interfaces.

What are access modifiers?

Access modifiers define the visibility of variables, methods, and classes. Java provides four types: public (accessible everywhere), private (within class), protected (within package and subclass), and default (within package).

What is constructor?

A constructor is a special method used to initialize objects. It has the same name as the class and does not have a return type. It is automatically called when an object is created.

What is this keyword?

The 'this' keyword refers to the current object. It is used to access instance variables, call constructors, and differentiate between local and instance variables.

What is static keyword?

The static keyword is used for memory management. Static variables and methods belong to the class rather than objects and are shared among all instances of the class.

What is final keyword?

The final keyword is used to restrict changes. A final variable cannot be modified, a final method cannot be overridden, and a final class cannot be inherited.

What is garbage collection?

Garbage collection is an automatic memory management process in Java. It removes unused objects from memory, helping to free resources and prevent memory leaks.

What is interface?

An interface is a collection of abstract methods. It is used to achieve abstraction and allows multiple inheritance. Classes implement interfaces using the 'implements' keyword.

What is exception handling?

Exception handling is used to handle runtime errors in a program. Java provides try, catch, finally, throw, and throws keywords to manage exceptions and prevent program crashes.

What is JVM?

JVM (Java Virtual Machine) is a part of Java runtime environment that executes bytecode. It converts bytecode into machine code and provides platform independence.

What is JDK and JRE?

JDK (Java Development Kit) is used for developing Java applications and includes JRE. JRE (Java Runtime Environment) provides libraries and JVM required to run Java programs.

What is method overloading?

Method overloading allows multiple methods with the same name but different parameters in the same class. It is an example of compile-time polymorphism.

What is method overriding?

Method overriding occurs when a subclass provides a specific implementation of a method already defined in the parent class. It supports runtime polymorphism.

What is String?

String is a class used to store text data in Java. It is immutable, which means once created, its value cannot be changed.

What is collection framework?

The collection framework provides classes and interfaces like List, Set, and Map to store and manipulate groups of objects efficiently.

Difference between Array and ArrayList?

Arrays have fixed size and can store both primitives and objects. ArrayList is dynamic, can grow or shrink, and stores only objects.

What is multithreading?

Multithreading allows multiple threads to run concurrently, improving performance and efficient CPU utilization in applications.

What is synchronization?

Synchronization controls access to shared resources in multithreading, preventing data inconsistency and ensuring thread safety.

What is equals() and hashCode()?

equals() compares object values, while hashCode() returns a unique hash value. Both are important for collections like HashMap.

What is wrapper class?

Wrapper classes convert primitive data types into objects. Examples include Integer, Double, and Character.

Difference between == and equals()?

'==' compares memory references, while equals() compares actual content of objects.
