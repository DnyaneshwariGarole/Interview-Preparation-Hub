SQL Interview Questions

What is SQL?

SQL (Structured Query Language) is used to manage and manipulate relational databases. It allows users to create, read, update, and delete data, as well as define database structure.

What is primary key?

A primary key is a column or set of columns that uniquely identifies each row in a table. It cannot contain NULL values and must be unique for every record.

What is foreign key?

A foreign key is a column that creates a relationship between two tables. It refers to the primary key in another table and ensures referential integrity.

What are joins?

Joins are used to combine data from multiple tables based on a related column. Common types include INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL JOIN.

What is normalization?

Normalization is the process of organizing data to reduce redundancy and improve data consistency. It divides tables into smaller related tables.

What is index?

An index is used to improve the speed of data retrieval operations. It works like a pointer that helps locate data quickly without scanning the entire table.

What is GROUP BY?

GROUP BY is used to group rows that have the same values in specified columns. It is commonly used with aggregate functions.

What is HAVING?

HAVING is used to filter grouped data after applying GROUP BY. It works with aggregate functions to filter results.

What is ORDER BY?

ORDER BY is used to sort query results in ascending (ASC) or descending (DESC) order based on one or more columns.

What is DISTINCT?

DISTINCT is used to remove duplicate values from the result set and return only unique records.

What is NULL?

NULL represents missing or unknown data in a database. It is different from zero or empty string and requires special handling.

What is constraint?

Constraints are rules applied on table columns to enforce data integrity. Examples include NOT NULL, UNIQUE, PRIMARY KEY, and FOREIGN KEY.

What is default constraint?

A default constraint assigns a default value to a column when no value is provided during insertion.

What is unique constraint?

A UNIQUE constraint ensures that all values in a column are different, but it can allow one NULL value.

Difference between WHERE and HAVING?

WHERE filters rows before grouping, while HAVING filters data after GROUP BY. WHERE cannot use aggregate functions, but HAVING can.

What is aggregate function?

Aggregate functions perform calculations on multiple rows and return a single result. Examples include COUNT, SUM, AVG, MIN, and MAX.

What is subquery?

A subquery is a query inside another query. It is used to retrieve data that will be used in the main query.

What is view?

A view is a virtual table based on a SQL query. It does not store data physically but displays data from one or more tables.

What is DELETE vs TRUNCATE?

DELETE removes specific rows and can be rolled back, while TRUNCATE removes all rows quickly and cannot be rolled back.

What is ACID?

ACID properties ensure reliable transactions: Atomicity (all or nothing), Consistency (valid state), Isolation (independent transactions), and Durability (permanent storage).

What is database?

A database is a structured collection of data stored electronically and managed using a database management system (DBMS).

What is DDL, DML, DCL?

DDL (Data Definition Language) defines structure (CREATE, ALTER), DML (Data Manipulation Language) manages data (INSERT, UPDATE), DCL (Data Control Language) controls access (GRANT, REVOKE).

What is UNION?

UNION is used to combine results of two or more SELECT queries and removes duplicate records.

What is UNION ALL?

UNION ALL combines results of multiple queries but includes duplicate records and performs faster than UNION.

What is INNER JOIN?

INNER JOIN returns only matching records from both tables based on a condition.

What is LEFT JOIN?

LEFT JOIN returns all records from the left table and matching records from the right table. If no match is found, NULL values are returned.

What is RIGHT JOIN?

RIGHT JOIN returns all records from the right table and matching records from the left table.

What is FULL JOIN?

FULL JOIN returns all records when there is a match in either left or right table. If no match exists, NULL values are returned.
