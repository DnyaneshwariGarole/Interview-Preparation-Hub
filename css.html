CSS Interview Questions

What is CSS?

CSS (Cascading Style Sheets) is used to style and layout web pages. It controls colors, fonts, spacing, positioning, and responsiveness of elements. It works along with HTML to make websites visually attractive.

Explain the CSS Box Model.

The box model consists of content, padding, border, and margin. It defines the layout and spacing of elements. The content is the actual data, padding adds space inside the element, border surrounds the padding, and margin creates space outside the element. Understanding it helps in designing layouts accurately.

What is Flexbox?

Flexbox is a one-dimensional layout system used to arrange elements in a row or column. It provides easy alignment, spacing, and distribution of elements even when their size is unknown. Properties like justify-content, align-items, and flex-direction make layout design simple and flexible.

What is CSS Grid?

CSS Grid is a two-dimensional layout system that works with both rows and columns. It allows developers to create complex layouts easily. Grid provides better control over placement of elements compared to flexbox when working with full page layouts.

Difference between margin and padding?

Margin controls the outer space between elements, helping to separate them. Padding controls the inner space between content and its border. Margin does not affect background color, while padding does.

What is display property?

The display property defines how an element appears on the page. Common values include block, inline, inline-block, flex, and grid. It plays a key role in layout structure and element behavior.

What is position property?

The position property controls how elements are positioned in a document. Values include static, relative, absolute, fixed, and sticky. It is used along with top, right, bottom, and left properties for placement.

What is z-index?

z-index defines the vertical stacking order of positioned elements. Elements with higher z-index appear above those with lower values. It only works on positioned elements like relative, absolute, or fixed.

What is float and clear in CSS?

The float property is used to position elements to the left or right of a container, allowing text and inline elements to wrap around it. The clear property is used to control the behavior of floating elements, preventing elements from wrapping around floated elements. It is commonly used in older layouts before flexbox and grid.

What is overflow property?

The overflow property controls what happens when content exceeds the size of its container. Values include hidden, scroll, auto, and visible. It helps manage layout when dealing with large or dynamic content.

What is visibility vs display:none?

visibility:hidden hides an element but still takes up space in the layout. display:none completely removes the element from the document flow, meaning it does not occupy any space. This difference is important for layout and UI behavior.

What is specificity?

Specificity determines which CSS rule is applied when multiple rules target the same element. Inline styles have the highest priority, followed by IDs, classes, and then elements. Understanding specificity helps avoid conflicts.

Inline vs Internal vs External CSS?

Inline CSS is applied directly inside HTML elements, internal CSS is written inside a style tag in the head section, and external CSS is stored in a separate file. External CSS is recommended for better maintainability and reusability.

What is responsive design?

Responsive design ensures that a website looks good on all screen sizes and devices. It is achieved using flexible layouts, media queries, and scalable images. It improves user experience across mobiles, tablets, and desktops.

What are media queries?

Media queries are used to apply CSS styles based on device characteristics such as screen width, height, and resolution. They are essential for building responsive web designs.

What is overflow?

It controls what happens when content overflows container. Values include hidden, scroll, and auto. It is useful when content does not fit inside a fixed-size element.

What is opacity?

Opacity controls the transparency of an element. A value of 0 makes it fully invisible, while 1 makes it fully visible. It is commonly used for hover effects and UI design.

Difference between class and id selector?

An ID selector is unique and used for a single element, while a class selector can be reused across multiple elements. IDs have higher specificity compared to classes.

What is pseudo-class?

Pseudo-classes define special states of elements such as hover, focus, and active. They allow styling based on user interaction without JavaScript.

What is pseudo-element?

Pseudo-elements are used to style specific parts of an element, such as ::before, ::after, ::first-letter, and ::first-line. They help in adding decorative content without modifying HTML.

What is rem vs em units?

em is relative to the font size of the parent element, while rem is relative to the root (html) font size. rem provides more consistent and predictable sizing across the entire page.

What is object-fit?

The object-fit property is used to control how images and videos fit within a container. Values like cover, contain, and fill help maintain aspect ratio and improve UI appearance.
