# 🎯 Interview Preparation Hub

A simple and responsive **Interview Preparation Website** built using only **HTML and CSS**.  
This project helps students and freshers quickly revise important interview topics with categorized questions and answers.

---

# 🚀 Features

- 📚 Subject-wise interview preparation
- 💡 Interview questions with answers
- 🎨 Clean and responsive user interface
- ⚡ Easy navigation between subjects
- 🖥 Beginner-friendly frontend project
- 📱 Responsive layout using CSS
- 📂 Separate pages for different subjects

---

# 🛠 Technologies Used

- HTML5
- CSS3
