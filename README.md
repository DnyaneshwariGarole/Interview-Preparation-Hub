# Interview Preparation Hub

A simple and clean interview preparation website built using HTML and CSS.  
This project contains important interview questions for multiple technical subjects like HTML, CSS, JavaScript, Java, SQL, and Spring Framework.

The main goal of this project is to help students quickly revise technical concepts before interviews.

# Features

- Multi-page interview preparation website
- HTML interview questions
- CSS interview questions
- JavaScript interview questions
- Java interview questions
- SQL interview questions
- Spring / Hibernate / JDBC questions
- Expand & collapse answers using HTML details tag
- Clean dashboard UI
- Two-column question layout
- Simple navigation buttons
- Beginner-friendly project structure

# Technologies Used

- HTML5
- CSS3
